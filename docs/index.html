Why Donkeh

A UI engine that respects the platform.

One component model, three very different hosts, and no JavaScript runtime required.

#

Real CSS, not a lookalike

Selectors, specificity, cascade layers, custom properties, media queries, keyframes, transitions, gradients, shadows and modern layout.

◫

One tree, four hosts

The same UILab tree renders to OpenGL on desktop, OpenGL ES on Android, or native DOM elements in the browser.

↻

Hooks and context

State, reducers, effects, memoisation, callbacks, refs and typed context providers with in-place reconciliation.

⌕

Built-in inspector

Inspect the live hierarchy, edit matched styles, sample frame/layout/render timings, browse keyframes and build targets.

⌘

A project CLI

Create blank-window projects and components, embed stylesheets automatically, and keep platform entry points out of your app.

◎

Host capabilities

Platform flags and awaitable camera, microphone, location, notification, storage and clipboard permission requests.

Quick start

From zero to a blank window.

Install the CLI, create a project, and run it. The framework supplies the platform entry point.

dotnet tool install --global Donkeh.CliTool
donkeh new project MyApp
cd MyApp
dotnet run

Add another platform later with donkeh enable-target android or donkeh enable-target web.
