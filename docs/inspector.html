Using the inspector

The inspector is a live, in-app devtools panel. It reads the same UILab tree the renderer draws and writes style edits back into the live stylesheet.

Enable it

Devtools are enabled by default on desktop. Set EnableDevTools = true on [AppRoot], or in WindowSettings when using the low-level window API. 

[AppRoot(
    Width = 1180,
    Height = 760,
    Title = "My app",
    EnableDevTools = true)]
public sealed class App : Component
{
    public override Node Render() => Div(new() { ClassName = "app" });
}

Open, close and dock

ActionHow
ToggleF12 or Ctrl+Shift+I
CloseThe close button in the toolbar
Dock bottomThe bottom-edge dock button; the app viewport shrinks above it.
Dock rightThe right-edge dock button; the app viewport shrinks beside it.
Window modeThe window dock button opens a standalone inspector window.
ResizeDrag the splitter between the app and the docked panel.

The panel can also be controlled from code: ShowDevTools(), HideDevTools(), ToggleDevTools() and DevTools.Dock.

Desktop and browser

The inspector is part of the desktop/Android renderer. The browser host renders into native DOM and leaves inspection to the browser devtools, which already know about CSS, layout and accessibility.
