LLM integration

The Donkeh CLI exposes project, component, CSX, CSS, renderer, documentation and diagnostic capabilities as JSON commands and as MCP tools. Packages can extend the same catalogue without modifying the CLI.

Discovery

Start with the overview, then inspect one capability or the MCP input schemas. Every agent-facing command accepts --json. 

donkeh mcp show --json
donkeh mcp capabilities csx.validate --json
donkeh mcp tools --json
donkeh mcp invoke csx.validate --file ./Components/Card.cx --json
donkeh inspect project --json
donkeh component search "file selection" --json

MCP server

donkeh mcp start hosts the same capability implementations on stdio. Tool results include text content and structured JSON. stdout is reserved for the protocol; diagnostics go to stderr. 

donkeh mcp start --project ./MyApp

CSX and CSS intelligence

CSX validation uses the shipped CSX transformer plus project props metadata. CSS validation uses the real tokenizer, data engine and LayoutLab property resolver, not a browser compatibility list. 

donkeh csx syntax components --json
donkeh csx validate ./Components/Card.cx --json
donkeh csx compile ./Components/Card.cx --generated --json
donkeh css property display --json
donkeh css validate ./styles.css --json

Package registration

A package adds a donkeh.llm.json manifest at its root. Static capabilities return declared JSON; executable providers implement ILlmCapabilityProvider and are loaded only when the manifest explicitly registers them. 

{
  "schemaVersion": 1,
  "package": "Acme.Donkeh.FileExplorer",
  "capabilities": [
    {
      "name": "acme.fileexplorer.components",
      "category": "Components",
      "summary": "List file explorer components.",
      "result": { "components": ["FileExplorer"] }
    }
  ],
  "components": [
    {
      "name": "FileExplorer",
      "kind": "assembly",
      "description": "A file browser with selection support.",
      "properties": [
        { "name": "ViewMode", "type": "string", "default": "\"List\"" }
      ]
    }
  ]
}

Names cannot override built-in namespaces or another package's MCP tool. Provider assemblies must stay inside the manifest directory, and the registry never executes shell commands on their behalf.

Token efficiency

Inspect a summary first, then request only the part you need: --properties, --events, --examples, --section, --summary or --limit. Generated CSX output, source maps and resolved bindings are opt-in.
