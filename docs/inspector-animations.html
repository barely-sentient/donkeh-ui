Using the animations tab

The Animations tab is a browser for every registered @keyframes group in the active stylesheets. It shows the stops and declarations the renderer will use.

Open the tab

Open the inspector, then choose Animations in the tab strip. The tab reads the current compiled CSS table; it does not sample the live animation clock.

The two panes

┌──────────────────────┬────────────────────────────────────────┐
│ @keyframes           │ @keyframes pulse                       │
│                      │ 3 declarations                         │
│ pulse                │                                        │
│ fade-in              │ from                                   │
│ slide-up             │   opacity: 0                           │
│                      │ 50%                                    │
│                      │   opacity: 1                           │
│                      │ to                                     │
│                      │   opacity: 0.6                         │
└──────────────────────┴────────────────────────────────────────┘
  • The left pane lists keyframe groups by name, in first-seen order.
  • Click a group to inspect it.
  • The right pane lists each stop, its declaration count and the property values.
  • If the selected animation disappears, the inspector falls back safely and shows an empty selection.
  • When no keyframes are registered, the tab shows a quiet placeholder instead of an empty list.

Where the groups come from

Any @keyframes rule parsed from the built-in or author stylesheets is collected. A typical component stylesheet looks like this: 

@keyframes pulse {
    from {
        opacity: 0.25;
        transform: scale(0.98);
    }

    50% {
        opacity: 1;
        transform: scale(1);
    }

    to {
        opacity: 0.25;
        transform: scale(0.98);
    }
}

.status-dot {
    animation: pulse 1.6s ease-in-out infinite;
}

The Animations tab groups the three stops under pulse. The card in the right pane also shows the number of declarations so a missing property is easy to spot.

What to check

CheckWhy
The name matches the animation propertyA typo creates no animation and no keyframe group is applied.
Stops are in the expected orderfrom/to and percentages are shown in source order.
Every stop has the properties you expectA missing declaration at one stop can produce a visible jump.
Vendor-neutral property namesThe engine uses standard CSS property names; verify transforms and filters in the styles pane.
Read-only view The Animations tab does not scrub a timeline or pause an animation. Use it to verify definitions, then edit the component stylesheet or the Elements tab to change them.

A practical workflow

  1. Locate the animation name in the left pane.
  2. Confirm every expected stop and property is present.
  3. Switch to Elements and select the animated element.
  4. Check the matched rule that declares animation, including duration, easing and iteration count.
  5. Edit the stylesheet, then reopen or refresh the inspector to see the updated keyframes.
Performance Prefer transforms and opacity for continuous animations. The Performance tab will show whether an animation is contributing to layout or render spikes.
